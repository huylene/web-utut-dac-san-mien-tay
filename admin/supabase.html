👤 Quản Lý Tài Khoản Quản Trị Viên (Admin)

Tạo tài khoản quản trị mới trên Supabase Auth và tự động gán quyền admin vào bảng profiles.

💡 Phân quyền quản trị viên bằng SQL

Nếu tạo user trực tiếp từ Supabase Auth Dashboard, chạy lệnh sau trong SQL Editor để cấp quyền: 

insert into public.profiles (user_id, role)
values ('USER_UUID_O_SUPABASE', 'admin')
on conflict (user_id) do update set role = 'admin';
